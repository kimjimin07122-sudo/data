# models — 대표 모델과 탐지 실험 코드

`uavprep`가 만든 npz를 읽어 **정상 비행만으로 학습한 예측 모델**로 결함을 탐지한다.
흐름: 입력 신호 → 예측 모델 → 점수(예측 오차) → 판정(평활·임계값) → 경보.
학습된 가중치와 결과 파일은 이 저장소에 없다(연구실 데이터셋으로 만든 것이 섞여 있음).

| 파일 | 내용 |
|---|---|
| `model.py` | Tiny Transformer 예측기 (입력 L×C → 다음 1스텝 상태 10채널) |
| `train_eval.py` | 학습 + 판정 + 평가 한 번에 (대표 모델) |
| `eval_variants.py` | 저장된 잔차로 평가 조건 V0~V3를 다시 계산 (재학습 없음) |
| `hundman_eval.py` | 방법1: 판정 바꾸기 — Hundman 2018 동적 임계값·가지치기 (재학습 없음) |
| `nll_train_eval.py` | 방법2: 예측 방식 바꾸기 — 값 + 흔들림(분산) 예측, 가우시안 NLL |
| `novelty_eval.py` | 방법3: 지령 이탈 점수를 기존 점수와 합침 (재학습 없음) |

방법3의 흔들림 폭 채널은 모델이 아니라 전처리 옵션이다: 설정 파일에 `"std_outputs": true`.

## 1. 사용법

```bash
# 대표 모델 (예: ALFA, 전체 공통 임계값)
python models/train_eval.py --npz data/alfa_L24.npz --L 24 --dt 0.25 \
    --sets normal,valid,engine,elevator,rudder --fault-sets engine,elevator,rudder \
    --n_in 17 --n_out 10 --seeds 0,1,2,3,4 --out runs --tag alfa
# 비행별 임계값 (UAV-SEAD, 기준선 10 s = 100스텝)
python models/train_eval.py ... --threshold-mode per-flight --baseline-steps 100

# 평가 조건 V0~V3 (exclude.json = 깨끗한 평가에서 뺄 비행 목록)
python models/eval_variants.py --run runs/<run> --dt 0.25 --exclude exclude.json --npz data/alfa_L24.npz --out eval

# 방법1·3 (저장된 run에 적용), 방법2 (재학습, 설정은 train_eval 인자와 같은 키의 json)
python models/hundman_eval.py --run runs/<run> --dt 0.1 --exclude exclude.json --npz <npz> --out eval --tag sead
python models/novelty_eval.py --run runs/<run> --npz <npz> --n-state 10 --dt 0.1 --out runs/<run>_novelty
python models/nll_train_eval.py --config config.json --out runs --tag sead
```
β는 `exp(−dt / 1.3 s)`로 고정해 쓴다(`--dt`가 데이터 주기와 맞아야 지연·β가 맞다).

## 2. 모델과 판정

| 항목 | 값 |
|---|---|
| 모델 | Tiny Transformer: d_model 32, 4-헤드, 인코더 2층, FFN 128, 배치 정규화, 시간축 평균, 파라미터 약 2.6만 |
| 학습 | 배치 192, Adam (학습률 0.0012993), 평균제곱오차, 최대 100 에폭 / 조기 종료 10, seed 5개 |
| 입력 → 출력 | 과거 L스텝(약 6초) × C채널 → 다음 1스텝 상태 10채널 |
| 잔차 | rₖ = ‖ ŷₖ − yₖ ‖ |
| 평활 | Rₖ = β · Rₖ₋₁ + (1 − β) · rₖ,  β = exp(−Δt / 1.3초) |
| 비행별 기준선 | Rₖ를 그 비행 처음 10초 잔차의 중앙값으로 나눔 (UAV-SEAD·연구실 데이터셋) |
| 임계값 | T = μᵥₐₗ + 3.291 · σᵥₐₗ (검증 정상 비행), Rₖ ≥ T이면 경보 |

## 3. 수치의 뜻

| 지표 | 단위 | 뜻 | 계산 |
|---|---|---|---|
| AUROC | 시점 | 점수가 결함과 정상을 얼마나 잘 가르나 (임계값과 무관). 0.5 = 무작위, 1 = 완벽 | 모든 시험 시점을 점수 순으로 세워 ROC 곡선 아래 넓이 |
| AUPRC | 시점 | 결함 시점을 점수 상위에 얼마나 모았나. 결함 비율에 따라 바뀜 | PR 곡선 아래 넓이 |
| 탐지 | 비행 | 결함 구간 안에서 경보가 한 번이라도 울린 비행 수 | — |
| 오경보 | 비행 | 결함 구간 밖(결함 전·후)에서 경보가 한 번이라도 울린 비행 수 | — |
| F1 | 비행 | 탐지와 오경보의 균형 | P = 탐지/(탐지+오경보), R = 탐지/전체, F1 = 2PR/(P+R) |
| 지연 | 초 | 결함 시작부터 첫 경보까지 (탐지한 비행만 평균) | (k_경보 − k_시작) · Δt |

- 모든 수치는 seed 5개로 각각 계산한 평균이다. 그래서 탐지가 11.8처럼 소수로 나온다.
- 평가 조건 (`eval_variants.py`):

| 조건 | 내용 |
|---|---|
| V0 원래 | 시험 비행 전체, 모든 구간 |
| V1 결함후제외 | 결함이 끝난 뒤 구간을 뺌 (추락·착륙이 정상 라벨로 남아 오경보가 되는 것을 막음) |
| V2 목록제외 | 결함 시작이 기준선 구간(처음 10초) 안이거나 볼 수 있는 결함 라벨이 없는 비행을 뺌 |
| **V3 둘다 (깨끗한 평가)** | V1 + V2. 아래 표의 기준 |

## 4. 결과 (깨끗한 평가 V3, seed 5개 평균)

연구실 데이터셋은 서약서 대상이라 이 저장소에는 수치를 싣지 않는다(연구실 내부 자료 참고).

### 대표 모델 (기준)
| 데이터셋 | 임계값 | AUROC | F1 | 탐지 | 오경보 | 지연 |
|---|---|---|---|---|---|---|
| ALFA | 전체 공통 | 0.929 | 0.944 | 11.8 / 12 | 1.2 | 7.0 s |
| UAV-SEAD | 비행별 | 0.765 | 0.600 | 20.6 / 42 | 6.0 | 11.3 s |

### 방법1: 판정 바꾸기 (Hundman et al., KDD 2018) — F1 / 탐지 / 오경보
| | 기준 | 가지치기만 | 동적 임계값 + 가지치기 | + 기준 임계값을 하한으로 |
|---|---|---|---|---|
| ALFA | 0.944 / 11.8 / 1.2 | 0.876 / 9.6 / 0.2 | 0.786 / 7.8 / 0.0 | 0.772 / 7.6 / 0.0 |
| UAV-SEAD | 0.600 / 20.6 / 6.0 | 0.559 / 17.8 / 3.8 | 0.262 / 6.6 / 1.6 | 0.247 / 6.0 / 0.4 |

- 오경보는 줄지만 탐지가 더 많이 줄어 F1 하락. 파라미터는 논문 값(z = 2.5~10, p = 0.13).
- 원인: 가지치기로 사라진 탐지는 결함 봉우리가 임계값의 1.0~1.3배로 겨우 넘은 비행 → **병목은 판정이 아니라 점수**.

### 방법2: 값 + 흔들림 예측 (가우시안 NLL) — AUROC / F1
| | 기준 | Sₙ = ‖(y − μ)/σ‖ | Sₘ = ‖y − μ‖ |
|---|---|---|---|
| ALFA | 0.929 / 0.944 | 0.909 / 0.831 | 0.911 / 0.913 |
| UAV-SEAD | 0.765 / 0.600 | 0.715 / 0.584 | 0.751 / 0.470 |

- 흔들림만 변하는 결함에서만 이득. 값이 크게 바뀌는 결함은 모델이 흔들림도 크게 예측해(결함 중 σ 1.7~1.8배) 나누면 신호가 깎인다.

### 방법3: 결함 특징에 맞춘 입력 신호
| | AUROC | F1 | 탐지 | 오경보 |
|---|---|---|---|---|
| UAV-SEAD + 지령 이탈 점수 | 0.765 → **0.870** | 0.600 → 0.661 | 20.6 → 27.2 / 42 | 6.0 → 13.0 |

- UAV-SEAD 결함 라벨은 사실상 추력 지령 포화(지도학습 모델 판단 근거의 62%). 지령은 입력이라 예측 오차로 안 보여 따로 점수화: sₖ = max(Rₖ/Tᵣ, Nₖ/Tₙ).
- 정상 비행을 다른 날짜 묶음으로 나눈 두 경우에도 0.851, 0.840으로 재현.
- 같은 옵션을 다른 데이터셋에 쓰면 오히려 떨어진다 → 공통 원칙이 아니라 **데이터셋별 옵션**.

### 최종 구성 (공통 전처리 + 데이터셋별 옵션)
| 데이터셋 | 옵션 | AUROC | F1 |
|---|---|---|---|
| ALFA | 없음 | 0.929 | 0.944 |
| UAV-SEAD | 지령 이탈 점수 (`novelty_eval.py`) | 0.870 | 0.661 |
| 연구실 데이터셋 | 흔들림 폭 채널 (`"std_outputs": true`) | 내부 자료 참고 | 내부 자료 참고 |
